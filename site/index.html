Windows에서 뜨는 경고에 대해

macOS 빌드는 애플 공증을 거쳐 경고 없이 열립니다. Windows 설치 파일은 아직 코드 서명이 없어 첫 실행에 "Windows의 PC 보호"가 뜹니다. 서명이 없다는 안내이지 악성코드 탐지가 아닙니다 — 인증서는 매년 비용이 들어서 아직 안 샀을 뿐이에요. 추가 정보 → 실행을 누르면 Windows가 기억합니다. 릴리스마다 SHA-256 체크섬을 올리니 직접 검증할 수도 있습니다.
